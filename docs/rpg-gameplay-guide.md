# RPG 新手与联合推理指南

## 五步开始

1. 群内发送 `/报名`；房主选择模组并发送 `/开始游戏`。
2. 加机器人好友，在私聊中查看并确认角色卡。
3. 开局后直接用自然语言描述行动；系统负责掷骰和数值结算。
4. 个人线索只在私聊显示，可用 `/分享线索 名称` 放入团队线索板。
5. 使用 `/推理 线索A + 线索B：结论` 发起联合推理，多人局由另一名玩家 `/赞成推理`。

`/跑团帮助` 会按当前阶段给出简短提示，也可指定报名、建卡、行动、线索或推理。
不希望自动提示时使用 `/跳过引导`；`/重新引导` 会让下局重新显示。

## 隐私边界

- `/线索板` 只展示已公开线索、来源提示、已完成推论和待确认提案。
- 玩家只能在推理中引用公开线索或自己持有的个人线索。
- 原始推理文本、个人线索正文、HP/SAN、NPC 私密情报不进入事件日志。
- 私聊失败时群内只提示加好友，正文不会回退到群内。

## 中断语义

服务关闭会直接终止当前对局，释放房间和行动队列并记录中断原因。旧局不会在重启后
恢复；局后回放只展示中断前已经写入的公开结构化事件。
