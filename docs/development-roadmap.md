# 开发路线图

路线按“先发布基线与模组质量，再观测和回放，最后补齐游玩体验”推进。每个任务应
保持独立提交，验收通过后再开始依赖它的任务。

## 当前状态

本轮已完成发布维护基线：README、`.env.example`、部署/迁移说明、CI、正式插件发现
自检和 `AI_API_KEY` 惰性初始化解耦。无 AI key 时 Bot 仍能启动，RPG 可通过
`RPG_AI_ENABLED=false` 明确运行确定性模式。

P1-1 固定种子模组试玩器已完成：CLI 与编辑器 TUI 均可对指定 seed 和目标结局执行
离线有界搜索，支持当前草稿/已保存文件、可复现轨迹、稳定 JSON 和失败诊断；不改在线
RPG 引擎语义。

P1-2 场景与结局静态可达性诊断已完成：编辑器 lint 按条件词条与可能写入来源做保守
固定点分析，报告条件阻断的场景/结局、无来源的 clue/flag/monster 条件和悬空出口；
P1-1 试玩器继续负责固定 seed 的可行路径验证。

P1-3 NPC 行程覆盖与秘密泄露检查已完成：编辑器 lint 按可玩时间窗口检查跨午夜行程、
不可达目标场景和永远不会命中的条件条目，并对 secrets/facts 到群播、KP 及 NPC 公共
上下文的精确文本路径做 ERROR 诊断；不改变在线 RPG 引擎语义。

P1-5 轻量事件日志已完成：定义共享 JSONL event envelope，并分别接入 RPG/狼人杀的
对局创建、开局、阶段、场景/具名事件、结构化行动和结局事件；每局用独立稳定 id 导出
有序事件。事件 payload 采用白名单，不记录提示词、密钥、QQ 号或任何消息/私密正文；
事件写入使用有界旁路队列，磁盘失败和队列满不阻塞引擎。

P1-6 运行指标已完成：提供进程内 counter/histogram 聚合与 Prometheus 文本导出，接入
RPG/狼人杀/对话队列拒绝、事件日志写入失败、游戏阶段耗时、AI 延迟/超时/降级和结局
分布。标签经过白名单限制，排除 game/group/user/actor 等高基数字段；指标更新失败
不影响游戏引擎。详见 `docs/metrics.md`。

P1-7 局后回放已完成：新增只读事件投影 API 和 `/回放` 命令，公开视角隐藏狼人杀
夜间行动，个人视角只增加当前座位自己的结构化行动；回放编号随正常结局公示，缺少
事件日志、创建边界或终局边界时明确提示不可回放。详见 `docs/game-replay.md`。

P2 新手引导与调查协作首版已完成：首次玩家按报名、建卡、行动、私人线索和联合推理
渐进接收私聊提示，可用 `/跑团帮助` 重看或跳过；新增共享 `/线索板`、确定性联合推理
状态机、`deduction:` 条件和三个含协作路径的模组。服务中断仍直接终止旧局，不恢复。

2026-08-18 已新增系统架构演示文稿 `docs/YawnBot-system-architecture.pptx`：覆盖
NoneBot/OneBot 入口、yawn_core 共享能力、RPG/狼人杀单写引擎、SQLite/LLM 边界、
启动隔离和后续可观测/可恢复路线。演示文稿只读现有源码与架构图，不改变运行时语义。

番茄免费小说可选子插件已完成首版及首轮故障修复：provider、公开字体解码、章节范围
交互、持久化任务/断点、单 worker 有界队列、权限链、私聊文件投递和 canonical 迁移
均已加入；搜索通过带持久化插件会话的 Playwright Chromium 执行公开搜索页，支持书名/
作者模糊搜索及相关/最新/最热排序，交互状态机新增男/女频阅读榜和新书榜分类浏览，

暂不可用，不登录、不提交验证码、不绕过访问控制；榜单只读取公开页面，不持久化结果。

番茄“免费预览补全”已完成：网页正文相对页面字数明显为预览时，只有同时明确

App 直连；失败后依次切换 `/api/raw_full`、fanqietc App 内容代理和管理员自备的
`FANQIE_MOBILE_HELPER_PATH`。各来源会校验标题或官网预览前缀、免费状态和正文长度；
付费或元数据不明确的章节不会调用任何补全来源。
