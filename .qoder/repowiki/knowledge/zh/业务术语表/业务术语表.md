### superusers
- 定义：超级用户集合，类型为 set[str]，存储在 NoneBot 配置中，用于权限控制。只有配置中的 QQ 号才能执行管理员命令，如好友审批操作。
- 别名：超管、管理员

### 好友申请审批
- 定义：当有 QQ 用户请求添加机器人为好友时，系统记录申请信息并通知 superusers 进行人工审批。支持同意（approve）和拒绝（reject）两种操作，审批结果通过 OneBot API 的 set_friend_add_request 方法执行。
- 别名：好友审批、friend_request

### pending
- 定义：好友申请的状态之一，表示待审批状态。每个用户的申请记录只保留一条，新申请会覆盖旧的 pending 状态记录。
- 别名：待审批

### approved
- 定义：好友申请的状态之一，表示已同意。审批通过后调用 OneBot API 正式添加好友。
- 别名：已同意

### rejected
- 定义：好友申请的状态之一，表示已拒绝。拒绝后不再允许该用户添加机器人为好友。
- 别名：已拒绝

### flag
- 定义：OneBot 协议中用于标识好友申请的唯一字符串，每次申请都会生成新的 flag，审批时必须使用正确的 flag 才能成功操作。
- 别名：申请标识

### CST
- 定义：中国标准时间（China Standard Time），UTC+8 时区。项目中用于统一时间显示，避免系统时区差异导致的时间混乱。
- 别名：北京时间、UTC+8

### event_preprocessor
- 定义：NoneBot2 的事件预处理钩子，在每条消息处理前执行。项目中用于追踪用户活跃状态，自动创建和更新 BotUser、UserGroup、BotGroup 记录。
- 别名：事件预处理

### upsert
- 定义：数据库操作模式，表示如果记录存在则更新，不存在则插入。项目中用于用户和群组记录的维护，确保首次出现时创建记录，后续消息仅更新时间戳。
- 别名：插入或更新

### first_interaction_at
- 定义：BotUser 表中的时间字段，记录用户第一次与机器人对话的时间，用于统计用户生命周期。
- 别名：首次对话时间

### first_seen_at
- 定义：UserGroup 和 BotGroup 表中的时间字段，分别记录用户第一次在群内发言和群组第一次被机器人认识的时间。
- 别名：首次出现时间

### last_interaction_at
- 定义：BotUser 表中的时间字段，记录用户最后一次与机器人交互的时间，每次消息处理都会更新此字段。
- 别名：最后活跃时间

### last_seen_at
- 定义：UserGroup 表中的时间字段，记录用户在群内的最后活跃时间，每次群消息都会更新。
- 别名：最后发言时间

### last_active_at
- 定义：BotGroup 表中的时间字段，记录群组最后活跃时间，每次群内有消息时更新。
- 别名：群组最后活跃
