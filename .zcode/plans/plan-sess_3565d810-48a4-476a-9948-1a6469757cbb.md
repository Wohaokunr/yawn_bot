# WebUI Agent「成员画像」面板优化方案

**目标**：Agent 详情页（`/agent/:groupId`）新增「成员画像」标签页，选择/输入成员后集中查看该成员在本群沉淀的全部画像（`profile` 普通画像 + `core` 晋升核心记忆 + `manual` 成员级置顶事实），并从「记忆」表格提供点击钻取入口。无 schema 变更、无新迁移。

## 后端：`src/plugins/yawn_core/webui/app.py`

新增端点 `GET /agent/groups/{group_id}/memories/subjects`（仿 `get_memories` 内联写法，`webui/src/.../app.py:554` 附近）：

1. 查询条件与 `get_memories` 同口径：`group_id` 匹配、`subject_user_id != 0`（排除群级行）、`visibility in ("group","public")`、未过期、`memory_type in ("profile","core","manual")`，复用 `_memory_privacy_clauses`（app.py:100）过滤隐私退出成员。
2. 取全实体 `order_by updated_at desc limit 5000`（与导出/图谱端点上限一致），在 Python 里按 `subject_user_id` 聚合 counts/total/latest updatedAt——与 `load_relation_graph` 的 degrees 聚合模式相同（service.py:802）。
3. 另查全群成员（`UserGroup join BotUser`，limit 5001，同图谱端点）构建昵称映射，避免大 `in_` 参数；退群残留成员昵称回退为空串。
4. 返回 `[{ "userId": str, "nickname", "groupNickname"|"None", "counts": {"profile","core","manual"}, "total", "updatedAt" }]`，按 updatedAt 降序；BigInt 一律转字符串（与 `serialize_memory` 同口径，服务端测试已有此约定）。

现有 `GET /agent/groups/{id}/memories?subjectUserId=X&pageSize=100` 已满足"单成员全部条目"取数，无需改动。

## 前端：`webui/src`

1. **types.ts**：新增 `MemorySubjectItem` 接口（上述 subjects 响应形状）。
2. **agent.tsx**：
   - 导出 `PROFILE_KEY_META` + `profileKeyLabel()`：`display_name=昵称/自称`、`preferred_address=偏好称呼`、`hobby=爱好`、`preference=偏好`、`skill=技能`、`recurring_topic=常聊话题`，未知 key 回退原值——与后端 `_FACT_KEYS`（memory.py:94）对齐，风格同 `MEMORY_TYPE_META`。
   - 新组件 `MemberProfilesPanel({ groupId })`：
     - 当前成员存 URL 参数（`?tab=profiles&userId=X`，replace 写入），支持从记忆页钻取与直链分享（仿 RelationsPanel 的 `?view=` 模式）。
     - 成员选择器用 `AutoComplete`（仿关系面板类型输入）：选项来自 subjects 接口，label 为 `昵称（QQ）· 画像n/核心m`，按昵称/QQ 过滤，允许直接键入任意 QQ 号。
     - 选中后经 `useApiQuery` 调 `/agent/groups/{id}/memories?subjectUserId=...&pageSize=100`；`meta.total` 超过返回条数时 Alert 提示截断。
     - 分组卡片展示：核心记忆（core，永久）→ 成员画像（profile）→ 置顶事实（manual，仅成员级）；每条含 key 中文标签、内容（可复制）、置信度/显著度 Progress、有效期、来源、更新时间，以及编辑/删除操作——复用现有 `PUT/DELETE /memories/{id}` 与编辑抽屉（含 `version` 乐观锁与 409 处理，同 MemoriesPanel）。
     - 头部统计行（画像/核心/置顶条数 + 最近更新），空态提示"画像由记忆整理自动生成，可在记忆页手工新增；隐私退出成员不展示"。
   - `AgentDetailPage` 注册 tab：`{ key: "profiles", label: "成员画像" }`，置于「记忆」之后、「关系边」之前。
   - `MemoriesPanel` 成员列 QQ 渲染为可点击链接 → `setSearchParams({ tab: "profiles", userId })` 钻取。
3. **agent.test.tsx**：新增 `PROFILE_KEY_META` 测试（键集合与后端 `_FACT_KEYS` 精确对齐防漂移、标签非空）与 `profileKeyLabel` 回退测试，风格同现有 `MEMORY_TYPE_META` 用例。
