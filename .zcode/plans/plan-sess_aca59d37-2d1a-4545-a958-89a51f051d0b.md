# Mimosa 深度安全审计计划

## 目标
对 `C:\Users\ASUS\project\Qbot\YawnBot` 整个代码库执行一次可复核的 Mimosa 密封深度安全扫描。

## 执行步骤

1. **加载技能规程**：调用 `mimosa:mimosa-security-scan` 技能，按其密封扫描流程操作。
2. **启动深度扫描**：通过 Mimosa MCP 的 `security_scan_start` 对项目根目录发起后台深度扫描（depth=deep，默认包含项目业务逻辑投研）。
3. **跟踪进度**：用 `security_scan_status` 轮询，直到扫描完成；如中断/失败则用 `security_scan_resume` 重试。
4. **汇报结果**：输出扫描摘要、覆盖状态与封印标识（scanId / seal），并对发现的问题逐条说明。

## 已知注意事项
- 根据既往经验，Mimosa 对 ORM `select(...)` 一行式写法存在 SQL 注入误报；结果中如出现此类告警，会结合代码上下文复核后再定性，不会直接当漏洞上报。
- 扫描历史默认写入 `~/.mimosa/security-scans/`（仓库外），不改动项目文件。

## 交付物
- 扫描摘要 + 封印标识 + 覆盖率状态
- 按严重程度整理的发现清单（附文件/行号与定性：真实问题 / 疑似误报）
