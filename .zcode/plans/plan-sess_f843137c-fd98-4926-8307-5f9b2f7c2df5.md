# 优化群聊 Agent 主动发言：逻辑修复 + 非常活跃档默认值

## 根因分析（为什么几乎不主动发言）

1. **冷却与被动回复共用 `last_agent_at`（最大杀手）**：被@后答话会刷新 `last_agent_at`（dialogue.py:837），而主动发言冷却检查的正是它（proactive.py:181，默认 20 分钟）→ bot 每被@一次，主动发言封锁 20 分钟，被@频繁的群永久哑火。
2. **概率低 + 窗口窄**：暖场 0.15/分钟且需先冷场满 30 分钟；插话 0.08/分钟且只在真人消息后 120s~8min 间隙有效（每间隙命中仅 ~39%）。
3. **内容门跳过也退避整个冷却**：骰子中了但 LLM 判定 speak=false / 调用失败 / 撞重时，`_apply_result` 把冷却推进满 20 分钟，中了也白还并进一步封锁。
4. **门槛多**：60 分钟真人消息 ≥3、每日上限 12。

## 修改内容

### 1. `data_models/group_agent_config.py` — 新列 + 默认值（非常活跃档）
- 新列 `last_proactive_at: Mapped[Optional[datetime]]`（主动发言专用冷却基准；`last_agent_at` 回归"bot 最近一次实际发言"语义）
- 默认值：`proactive_probability` 0.15→**0.35**、`idle_threshold_minutes` 30→**15**、`cooldown_minutes` 20→**8**、`proactive_active_probability` 0.08→**0.25**、`proactive_active_window_minutes` 8→**12**、`daily_limit` 12→**30**

### 2. `yawn_agent/context.py`
- `ActivitySnapshot` 增加可选字段 `last_proactive_at: datetime | None = None`（两处构造点均关键字传参，向后兼容；对话路径不改）

### 3. `yawn_agent/proactive.py` — 判断逻辑核心改造
- 常量：`_ACTIVE_MIN_GAP_SECONDS` 120→**90**、`_ACTIVE_MIN_MEMBER_MESSAGES` 3→**2**；新增 `_POST_REPLY_GUARD_MINUTES = 5.0`、暖场概率封顶 0.6
- **冷却拆分**（should_proactively_speak）：
  - 主动→主动：`last_proactive_at + cooldown_minutes` → 拒绝
  - 被动回复后守卫：`last_agent_at + 5 分钟` → 拒绝（替代原 20 分钟全面封锁）
- **暖场概率随冷场时长爬坡**：阈值时 1x → 2 倍阈值时 2x（0.35→0.7 封顶 0.6），纯函数便于测试
- **跳过退避减半**：`_apply_result` 成功时同时设 `last_proactive_at`/`last_agent_at`；跳过/LLM失败/撞重时只把 `last_proactive_at` 回拨到剩余 `max(2, cooldown//2)` 分钟，不动 `last_agent_at`（提取小纯函数计算回拨时间戳）
- `_collect_candidates` snapshot 传入 `last_proactive_at`
- **提示词软化**：`_ACTIVE_INTERJECT_PROMPT`/`_WARMUP_PROMPT` 改为"默认值得开口、仅明显不合适才沉默"的倾向，JSON 协议不变

### 4. 新 Alembic 迁移 `data/nonebot_plugin_orm/migrations/yawn_core/<rev>_agent_proactive_tuning.py`
- 接在当前 head `b3c4d5e6f7a8` 之后
- `batch_alter_table` 加 `last_proactive_at`（DateTime 可空，不加 server_default，遵循 e5b8a0f4d3c2 的项目约定）
- **数据迁移**：只更新等于旧默认值的存量行（浮点用容差比较，用户自定义的群不受影响）→ 上述 6 项新默认值；downgrade 反向 + 删列

### 5. `yawn_agent/commands.py`
- `/Agent设置` 新增 `插话概率 <0-1>`、`冷却 <分钟>` 子命令（沿用现有 clamp/提交/文案模式）
- `/群聊Agent` 状态文案补充插话概率与冷却展示

## 预期效果
- 热闹群：话题间隙（90s~12min）大概率插话（每间隙 ~95%），被@后只挡 5 分钟
- 冷场群：15 分钟即开始暖场，冷得越久概率越高（0.35→0.6）
- LLM 拒绝只退避 4 分钟（原 20 分钟）；每日 30 条上限兜底防刷屏，WebUI/命令仍可按群调整
