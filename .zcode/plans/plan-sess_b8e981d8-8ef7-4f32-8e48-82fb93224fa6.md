# 狼人杀 & 跑团子插件接入 WebUI

## 总体设计

- 后端新增 `src/plugins/yawn_core/webui/games.py`(兄弟 APIRouter,复用 `API_PATH` 前缀、`ReadSession`/`WriteSession`、`ok()`/`page_meta` 信封、审计中间件自动覆盖写操作)。
- 实时对局数据**只读内存**(`yawn_werewolf.state._games` / `yawn_rpg.state._games`),延迟导入 + try/except,子插件未加载时返回 `available: false` 而非报错。
- 强制结束复用现有 `stop_game()`(与群内 `/结束游戏` 同一状态机入口,不绕过引擎单写约束),用 `asyncio.create_task` 后台执行立即返回。
- 战绩数据查 ORM 总结表(WerewolfGame/Player、RPGGame/Player)。
- 概览页插件状态卡片补上两个子插件的加载状态(`service.py` 的 `wanted` 集合加 `"狼人杀"`, `"跑团"`)。

## 后端改动

### 1. 新文件 `webui/games.py`
- 模块级缓存子插件状态模块的延迟加载器 `_werewolf_state()` / `_rpg_state()`,ImportError 时返回 None。
- `GET /games/live` → `{werewolf: {available, games: [...]}, rpg: {available, games: [...]}}`
  - 狼人杀每局:groupId、groupName(联 BotGroup)、hostUserId、board、phase+中文标签、roundNo、人数、AI 人数、队列深度、待处理数、worker 存活、players[](座位/名字/userId/isAi/存活/警徽/**role、faction、死亡轮次**——完整信息,前端默认遮蔽)。
  - 跑团每局:groupId、groupName、hostUserId、moduleId/name、phase、当前场景名、探索轮/战斗轮与当前行动者、时钟(均为 /局面 公共信息口径)、队列深度、tools_broken 降级标记、players[](userId/角色名/倒地状态;**不含 HP/SAN**,遵守"群内渲染只含公共信息"的隐私约束)。
- `POST /games/werewolf/{group_id}/stop` / `POST /games/rpg/{group_id}/stop`(WriteSession):
  - 无活跃对局返回 404;有则 `create_task(stop_game(...))`,广播 `hub.notify_change`,返回 `{stopping: true}`。
- `GET /games/werewolf/history` / `GET /games/rpg/history`(`?page&pageSize&search&groupId&status=running|finished`):
  - 分页查总结表,联 BotGroup 补群名,批量带出 players 行(狼人杀:座位/角色/阵营/胜负/死亡;跑团:角色名/初始与最终 HP/SAN/存活/倒地)。
- 所有时间序列化沿用 `service.py` 的北京时间 `iso()` 约定。

### 2. `webui/app.py`
- `register()` 中 `app.include_router(games_router)`。

### 3. `webui/service.py`
- `overview()` 的 `wanted` 集合加入 `"狼人杀"`、`"跑团"`,概览页插件状态卡自动显示二者加载状态。

## 前端改动(webui/src)

### 4. `types.ts`
- 新增 WerewolfLiveGame、RpgLiveGame、LiveGamesSnapshot、WerewolfHistoryGame/Player、RpgHistoryGame/Player 接口。

### 5. `App.tsx`
- 侧边栏菜单新增「对局监控」(PlayCircleOutlined 图标),路由 `/games`,放在 Agent 管理与操作审计之间。
- `GamesPage` 三个 Tab:
  - **实时对局**:顶部子插件可用性 Alert(未加载时提示);两节表格(狼人杀/跑团)或按类型 Tag 合并;列:类型/群/房主/阶段/轮次/人数(AI)/队列/操作(强制结束,Popconfirm 二次确认);行展开显示玩家明细;**5 秒轮询刷新**;狼人杀角色列默认显示 🙈,顶部「显示身份」Switch 打开后才显示真实角色(防误泄)。
  - **狼人杀战绩**:搜索群号 + 状态筛选 + 分页表格,展开行显示玩家(角色/阵营/胜负/死亡轮次),胜负 Tag 软糖胶囊。
  - **跑团战绩**:同构,展开行显示玩家(HP/SAN 起终、存活、倒地),结局/终止原因 Tag。
- 复用现有 PageHeader、formatTime、Popconfirm、Table 分页模式,风格延续樱花粉二次元主题。

## 验证

- 后端:Ruff + Pyright + pytest(检查 tests/ 下现有 webui 测试模式并补充 games 路由的测试,遵循现有用例写法)。
- 前端:`npm run typecheck` + `npm run test -- --run` + `npm run build`(dist 重新构建,重启 bot 即生效)。
- 浏览器:临时 mock 后端扩展 games 端点,视觉验证新页面(登录态 + 实时对局/战绩两个 Tab 截图),验证完清理 mock 与 dev server。

## 边界与约束遵守

- 不直接写报名名单/房主/局内状态——强制结束只走 `stop_game()`(commands.py 同款 `_spawn_background` 模式)。
- 跑团实时视图只暴露 /局面 公共信息口径,不含 HP/SAN/个人线索。
- 子插件缺失/未加载时所有端点优雅降级,不影响 WebUI 其余功能。
- 不提交 git;构建产物更新到 webui/dist。
