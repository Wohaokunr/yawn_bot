# 番茄小说 WebUI 界面美术优化方案

方向已确认:**书封卡片网格 + 番茄红点缀**(在樱花粉基础上引入番茄红 #ff8a70 系作页面局部强调)。纯视觉层改动,不动 API 调用、轮询逻辑、表单校验与纯函数签名。

## 改动文件

1. `webui/src/fanqie.tsx` — 页面结构重构
2. `webui/src/styles.css` — 新增 `fq-*` 专属样式段(参照狼人杀页 `ww-*` 的组织方式)
3. `webui/src/fanqie.test.tsx` — 新增 `coverThemeIndex` 确定性小测试(可选)

## fanqie.tsx 组件改动

1. **页面英雄横幅**:available 分支的 `PageHeader` 替换为自定义 `fq-hero` — 🍅 渐变标记(番茄红→樱花粉)+ 标题副标题 + 三个统计 chip(排队 N / 下载中 N / 单次上限 N 章)+ 角落 📖✨ 装饰(twinkle 动画)。加载中/子插件未加载分支保持现状。
2. **新增纯函数 `coverThemeIndex(bookId)`**:字符码求和 % 8 选书封主题,同一本书永远同色。
3. **选书结果改书封卡片网格** `BookCardGrid`(替换 `BookResultsTable`):
   - 每本书一张卡:生成式书封(3:4 比例、8 套多彩渐变主题、书名首字 ZCOOL 大字、书脊高光)+ 书名/作者/简介两行截断 + 「选这本书」按钮
   - 榜单模式下 TOP1-3 显示 🥇🥈🥉 徽章,其余显示 #n 小 chip(搜索/链接模式不显示)
   - hover 卡片上浮 + 封面光泽扫过;入场逐卡错峰浮现(backwards fill 防轮询重播)
   - `grid auto-fill minmax(168px, 1fr)` 自动响应式
4. **模式切换美化**:Segmented 加 `fq-modes` 类,选中项番茄渐变胶囊。
5. **BookDrawer**:头部改为大书封 + 书名/作者/BookID/简介并排块(替代 Descriptions),加章节统计 chip(共 N · 公开 N · 锁定 N);目录加载态改 Skeleton;提交表单结构不变。
6. **状态胶囊**:`jobStatusTag`/`sendStatusTag` 改自定义 `fq-status` 样式(浅色底 + 彩色圆点,下载中圆点呼吸动画),未知状态回退 antd 默认 Tag;任务表与详情抽屉自动生效。
7. **JobsTab**:仅表格空状态美化(引导去「找书下载」),列表仍用 Table(管理场景正确形态)。

## styles.css 新增 fq-* 段

- `--tomato-100..600` 色阶变量
- `fq-hero` 横幅(渐变、圆角 22px、模糊光斑、chip 样式)
- `fq-modes` Segmented 覆盖、`fq-book-grid`/`fq-book-card`/`fq-cover`(8 套主题类)/`fq-rank` 徽章/光泽 keyframe
- `fq-book-head` 抽屉头部、`fq-status` 状态胶囊
- 复用现有动效令牌(`--ease-soft/spring`、`breathe`、`twinkle`)与全局 `prefers-reduced-motion` 降级;小屏 chips 换行、网格自动收窄

## 不改的部分

- 所有 fetch/轮询/`useApiQuery`/URL tab 逻辑、`fanqieRangeError`/`fanqieJobActions`/`FANQIE_JOB_STATUS_META` 导出签名 — 现有测试保持绿
- 后端 API、types.ts、App.tsx 路由与菜单
