在根 `.gitignore` 末尾追加 Mimosa 插件的本地扫描产物忽略规则：

```gitignore
# Mimosa security-scan plugin local artifacts (root and nested, e.g. webui/)
.mimosa/
```

说明：
- 模式 `.mimosa/` 不含中间斜杠，会匹配任意深度下名为 `.mimosa` 的目录，因此同时覆盖根目录 `.mimosa/` 与 `webui/.mimosa/`，无需两行。
- 两个目录当前均为未跟踪状态（`??`），不涉及 `git rm --cached` 解除跟踪或额外提交。
- 修改后用 `git status` 验证这两个目录不再出现在未跟踪列表中。
