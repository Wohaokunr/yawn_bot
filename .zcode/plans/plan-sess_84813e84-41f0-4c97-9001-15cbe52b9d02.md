# 关系图谱前端优化：拖拽联动 + 美术升级 + 动画 + 最大化

## 改动文件
- `webui/src/relation-graph.tsx`（核心改动）
- `webui/src/styles.css`（新增 rg-* 动画与最大化样式）
- `webui/src/relation-graph.test.tsx`（新增模拟器纯函数测试）
- `webui/src/dev-preview.tsx` + `webui/dev-preview.html`（**仅开发用**视觉预览页，含 mock 数据，不进生产构建）

所有现有导出纯函数（`runRelationLayout`/`edgePath`/`fitTransform`/`wheelZoom` 等）签名与行为保持不变，现有测试不动。

## A. 拖拽带动周围节点（实时力导向模拟）

1. 新增导出纯工厂 `createRelationSimulation(nodeIds, links, positions, pinned)`：
   - 与 `runRelationLayout` 完全相同的力参数（link 距离按置信度、charge -180、collide 30、x/y 向心力），从给定位置种子化，`.stop()` 返回（deterministic、可测试）。
   - 之前被用户钉住的节点设 `fx/fy` 作为锚点。
2. 组件内交互逻辑：
   - 阈值 `LIVE_SIM_MAX_NODES = 300`：≤300 节点走实时模拟；超大图保持现有"仅钉住"行为（保 5000 节点上限下的性能）。
   - 节点 pointerdown：惰性创建/复用 simulation（按 layoutSignature 失效重建），`alphaTarget(0.28).restart()`，被拖节点每次 move 直接设 `fx/fy` 为指针世界坐标（用 svgRef rect + transform 反算，无漂移）。
   - `sim.on("tick")` → 更新 `simPositions` state（Map 覆盖布局位置），邻居被弹簧力牵动。
   - pointerup：`alphaTarget(0)` 让系统冷却沉降；`on("end")` 把最终位置全部写入 `pinnedRef`（拖后图保持稳定，双击解钉 / 重布局清除逻辑不变）。
   - 卸卸载/布局签名变化时 `sim.stop()` 清理。
3. 渲染层位置合成顺序：`layout → pinnedRef → simPositions → dragPos`（大图退化路径仍用 dragPos）。

## B. 最大化功能

- 新增 `maximized` state + 工具栏按钮（`ExpandOutlined`/`CompressOutlined`，Tooltip「最大化查看 / 还原（Esc）」）。
- `.rg-wrap.rg-maximized`：`position: fixed; inset: 14px; z-index: 900; height: auto; border-radius: 22px`，浮层卡 + 大阴影 + pop-in 弹入动画；配 `.rg-maximize-backdrop`（z-index 899 半透明遮罩，点击可还原）。
- Esc 键还原；最大化期间 `document.body.style.overflow = "hidden"` 锁滚动。
- 尺寸变化经现有 ResizeObserver → 自动重新 doFit 适配。
- antd Drawer（节点/边详情）z-index 更高，在最大化之上正常弹出。
- 提示文案更新：「拖动会牵动相邻节点 · 双击解除固定 · 滚轮缩放 · 空白拖拽平移 · Esc 退出最大化」。

## C. 视觉升级（沿用樱花粉主题 token）

- **节点**：SVG `<defs>` 按角色加 5 个 `radialGradient`（左上高光的糖果立体感）；节点结构改为外层 `translate` + 内层 `rg-node-core`（CSS hover scale 1.12 弹簧放大，不与位移冲突）；选中态改为旋转虚线环（`#d63f71`）+ 呼吸光环。
- **边**：active 边增加同色半透明"辉光垫底路径"（宽 +5、opacity 0.25，无 filter 保性能）；mentions 虚线边加 dash 流动动画；边 label 出现时轻微上浮弹入。
- **画布**：`.rg-wrap::before/::after` 两个大半径柔光色块（樱花/薰衣草 radial-gradient，慢速漂移动画，opacity 低），叠在现有点阵纹理上。
- **图例/提示**：legend dot 按类型色加微光 box-shadow；hint 改玻璃胶囊样式，与 toolbar 同语言。
- **入场动画**：节点按索引 staggered pop-in（复用 `pop-in` 语言，`--i` 变量延迟），边随后淡入。

## D. 缩放/适配平滑过渡

- 视口 `<g>` 改用 CSS `style.transform`（代替 attribute），程序性变换（适配全图、放大/缩小按钮、最大化 re-fit）时启用 `transition: transform .45s var(--ease-soft)`，滚轮/拖拽/平移时关闭保证即时响应。
- 所有新动画自动被现有 `prefers-reduced-motion` 全局规则禁用。

## E. 开发预览页（视觉迭代与验证）

- `webui/dev-preview.html` + `src/dev-preview.tsx`：直接渲染 `RelationGraphView`，mock ~14 成员 / ~20 边（覆盖各角色、多类型边、平行边、mentions 虚线、孤立节点、truncated meta），复用 main.tsx 的 antd 主题 token。
